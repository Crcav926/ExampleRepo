# ExampleRepo
An example Repo for Painter's CSE 3902 Course. Note: There is currently no usable code in this repo and this is meant to be a guideline, not a requirement or rule for anyone!

Basic setup:
- Sprint master branch -- containing a fully functional iteration of the current sprint
- Individual feature branches: Features that are forked off the sprint branches, these should be quick, individual branches with a short lifespan.
- Feature branches continued: Features should be as mutually exclusive as possible, this prevents merge hell.
- Hot-Fix/Bug Branches: Something break in the main branch? Create a small, quick branch to fix the bug and track that it has been fixed.
